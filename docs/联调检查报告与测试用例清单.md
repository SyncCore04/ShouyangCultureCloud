```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态资源
    location / {
        root /usr/share/nginx/html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 上传文件
    location /uploads/ {
        proxy_pass http://127.0.0.1:8080;
    }
}
```

## 二、发现的问题与修复建议

### 问题 1：路由切换未滚动到顶部（优先级：中）
**现象：** 从列表页点击进入详情页，页面停留在当前滚动位置。
**修复：** 在前台 `router/index.js` 中添加：
```js
router.afterEach(() => {
  window.scrollTo(0, 0)
})
```

### 问题 2：部分页面缺少空状态（优先级：低）
**现象：** 部分列表页数据为空时显示空白。
**修复：** 在列表为空时显示 `<el-empty description="暂无数据" />`。

### 问题 3：富文本内容样式需优化（优先级：中）
**现象：** 资讯详情页富文本内容图片可能溢出，段落间距不一致。
**修复：** 在全局样式或详情页 scoped 样式中添加 `.rich-content` 样式（见上文）。

### 问题 4：生产环境部署文档待补充（优先级：低）
**现象：** 缺少 Nginx 反向代理配置说明。
**修复：** 在项目 README 或部署文档中添加 Nginx 配置（见上文）。

### 问题 5：XSS 防护可选增强（优先级：低）
**现象：** 富文本内容未做 HTML 过滤。
**修复：** 毕设项目可暂不处理，如需要可用 hutool 的 `HtmlUtil.filter()` 过滤。
